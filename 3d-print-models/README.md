# 3d-print-models

3D 列印用的模型檔案放在這個資料夾。這裡不是 Blender 原始碼的一部分。

## 檔案怎麼存

- 這個資料夾裡的模型檔以一般 Git 檔案儲存，**不使用 Git LFS**（見同資料夾的 `.gitattributes`，它覆蓋了根目錄的 LFS 規則）。
- 好處是網頁上傳和一般 `git push` 都不需要安裝 git-lfs。
- 限制：單一檔案超過 100 MB，GitHub 會拒絕；用瀏覽器上傳時，單檔上限約 25 MB。

## 建議

- 檔名盡量使用英文、數字、`-` 和 `_`，避免空白和特殊符號。
- 3D 列印用的 STL、3MF 單位請使用毫米（mm）。
- 每個作品建議一個子資料夾，例如 `3d-print-models/rock-01/`，裡面放 `.stl`、`.blend` 和預覽圖。
- 一次上傳不要超過 100 個檔案（瀏覽器上傳的限制）。
